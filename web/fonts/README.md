# Geist Sans

`Geist-Variable.woff2` is the variable-weight Geist Sans font from [vercel/geist-font](https://github.com/vercel/geist-font), distributed under the [SIL Open Font License 1.1](OFL.txt).

Source: `fonts/Geist/webfonts/Geist[wght].woff2`. It is served locally; the dashboard does not request fonts from an external CDN. Chinese characters use the system's CJK font fallback.
